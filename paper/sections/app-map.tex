\section{Experiment map}\label{app:map}

The main text names experiments by what they do. Their codes, which the appendices and the released files
use, are defined only here. Table~\ref{tab:app-map} gives, for each, where it is reported, what it tests, where
and how often it ran, the library commit, the versions of stores and engines, and the run identifiers. Numeric run
identifiers are GitHub Actions runs of the library's repository unless marked; \emph{E} is the enterprise corpus and
\emph{M} the MS MARCO corpus. No single version of the library was evaluated throughout
(Appendix~\ref{sec:limits-limits}).
